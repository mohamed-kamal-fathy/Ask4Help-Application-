

### 1. Ask4Help Application (Manual Testing)
**GitHub Repository:** [github.com/mohamed-kamal-fathy/Ask4Help-Application](https://github.com/mohamed-kamal-fathy/Ask4Help-Application)

**Project Description:**  
A web-based platform that connects users needing assistance with volunteers who can help. The testing process focused on functionality, usability, and reliability.

**Testing Activities:**
- Created comprehensive test cases using Excel
- Performed manual testing of all user flows
- Identified, documented, and tracked bugs using Jira
- Set up local testing environment with XAMPP (Apache, MySQL, PHP)
- Verified database integrity and API responses
- Conducted UI/UX testing

**Technologies Used:**
- Testing Tools: Excel (test cases), Jira (bug tracking)
- Environment: XAMPP (Apache, MySQL, PHP)
